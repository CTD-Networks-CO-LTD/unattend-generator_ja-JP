Partitioning and formatting
Select target disk The hard drive is disk (0-based).
Choose partition layout
This will attempt to detect the firmware type (BIOS or UEFI) and select the partition layout (MBR or GPT) accordingly.
The GPT partition layout must be used for UEFI systems.
The MBR-based partition layout must be used for legacy BIOS systems.

Drive letter assignments in the script (e.g. ASSIGN LETTER=W) solely affect the Windows PE stage of Windows Setup. These assignments do not persist to the new installation, which will always assign the C: drive letter to the Windows partition.
You will have to enter the commands to partition and format your disks. There is no graphical user interface.
Verify disk numbers
When you let Windows Setup wipe and partition your disks, there is a risk they were assigned unexpected index numbers. For example, on some computers, disk 0 might refer to a USB flash drive instead of the primary hard drive. To make sure that Windows Setup targets the intended disk, you can make assertions about that disk. If these assertions are not met, Windows Setup will halt to avoid data loss.
