Generate autounattend.xml files for Windows 11

This service lets you create answer files to perform unattended installations of Windows 11, including 24H2, 25H2 and 26H2. Answer files generated by this service are primarily intended to be used with USB flash drives or in virtual machines to perform clean (rather than upgrade) installations.
