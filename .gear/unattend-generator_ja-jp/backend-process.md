# バックエンド処理

| id | processName | description | input | output | relatedApi |
| --- | --- | --- | --- | --- | --- |
| BP-001 |  | インストール設定フォームに入力された各種パラメータ（GenerationContext）を解析し、無人セットアップで使用される自動応答ファイル（autounattend.xml）を一括構築する。内部的には各設定のModifierをパイプライン順に実行し、XmlNodeツリー、各種Passフェーズ設定、PowerShellSequenceスクリプト等を統合・シリアライズする。 |  |  |  |
| BP-002 |  | 無人セットアップ時の言語およびキーボード設定において、日本語(ja-JP)および日本語キーボード（106キー/109キー）用の特化処理を自動定義する。windowsPEでのLayeredDriver割り当てに加え、レジストリ書き換えによる106キーボートドライバの永続適用、言語リスト（New-WinUserLanguageList）の構成とシステムプロファイルへのコピーを行うスクリプトを自動生成する。 |  |  |  |
| BP-003 |  | ディスク構成およびパーティションレイアウト（MBR、GPT、自動選択）に基づき、ディスク構成コマンドファイル（diskpartスクリプト等）またはインストール先のターゲットディスク選択処理を設定フェーズへ自動定義・埋め込む。 |  |  |  |
| BP-004 |  | クリーンインストール後のシステムをクリーンに保つため、無人セットアップ中（specialize、userOnce、defaultUserフェーズ等）に不要な既定プリインストールアプリ（OneDrive、Copilot、Cortana、Outlook等）を自動的に一括削除するPowerShellコマンド（Remove-AppxProvisionedPackage）を埋め込むスクリプトを生成する。 |  |  |  |
| BP-005 |  | セットアップ完了後のデスクトップ環境におけるUI/UXの利便性を向上させる目的で、クラシックコンテキストメニューの有効化、ファイル拡張子の常時表示、アプリ提案の非表示化などを行う。レジストリ変更コード（reg.exeまたはPowerShell経由）を、DefaultUserのNTUSER.DATマウント・書き換えコマンドとして自動応答ファイルに注入する。 |  |  |  |
| BP-006 |  | 無人セットアップ時におけるローカル管理者（Administratorsグループ）および一般ユーザー（Usersグループ）のアカウント設定（最大10件まで）、および自動サインオン（AutoLogon）、パスワード有効期限ポリシー、アカウントロックアウト閾値・制限ポリシーを適用するコマンド群を設定する。 |  |  |  |
| BP-007 |  | 生成した自動応答ファイル（autounattend.xml）を、CD-ROMとしてマウント・読み込み可能なISO 9660ファイル（autounattend.iso）のバイナリ（Blob形式）にブラウザ上で動的変換し、即時ダウンロード保存する機能。 |  |  |  |
| BP-008 |  | 無人セットアップ中（OOBE開始時）にワイヤレスネットワークへ接続可能にするため、Wi-Fiプロファイル（Wifi.xml）を構成してシステム内へ埋め込む。さらに、WlanSvc（WLAN AutoConfig）の起動完了を監視するPowerShell待機ループを生成・実行し、netsh.exeコマンドによりプロファイルをシステムに自動登録・有効化する。 |  |  |  |
| BP-009 |  | 特定のグループポリシーまたはデバイス制御規制においてAppLockerを構成する（AppLockerModeがConfigureの）際、入力されたポリシー記述用のXML（AppLockerPolicy.xml）を自動応答ファイル内に直接埋め込み、AppIDSvcサービスを自動的に有効化して適用する。 |  |  |  |
| BP-010 |  | 既存の自動応答ファイル（XML）をクライアントサイドで読み込み、その先頭部分のコメントブロック内にシリアライズ保存（埋め込み）されている設定クエリ文字列（?LanguageMode=Unattended...等）を検出・解析して、フォーム画面上の各パラメータへ設定値を反映させる。 |  |  |  |
| BP-011 |  | Windows 11 の最小システム要件（TPM 2.0、セキュアブート、搭載RAM容量制限）を満たさない古いハードウェアへクリーンインストールを許可するためのレジストリ回避設定（BypassRequirementsCheck）や、OOBE中におけるネットワーク強制確認のスキップ（BypassNetworkCheck / BypassNRO）および簡易設定（ExpressSettings）の動作を自動応答ファイル内で構成する。 |  |  |  |
| BP-012 |  | Cloudflare Workersなどのサーバーレス環境で稼働するバックエンドAPIエンドポイントを介して、パラメータ（POSTされたFormData、またはGETパラメータ）を受け取り、サーバーレス上でクライアントと同様の応答ファイル生成ロジックを実行または中継し、XMLデータのプレビュー、XMLファイルダウンロード、またはISOダウンロード用のレスポンスを返却する。 |  |  |  |
