# システムテスト観点

## テスト観点ツリー

### STV-L1-001 機能

#### STV-L2-001 日本語キーボードおよびロケール自動適用確認 (日本語環境およびキーボード配列設定 (F-004))

- **STV-L3-001 日本語106キーボードドライバ・レジストリ自動生成確認** [高]
  - インストール設定フォーム画面 (SCR-001) の「Keyboard」選択ボックスで日本語（00000411）を選択した際、内部の GenerationContext に kbd106.dll の適用と PCAT_106KEY のレジストリ書き換え処理が自動スケジューリングされること。
  - 応答ファイルジェネレーター画面 (SCR-002) で生成された autounattend.xml の初期セットアップ WinPE フェーズにおいて、キーボードレイヤードライバが「1」に設定されていること。
  - specialize および firstLogon のシーケンスにおいて、日本語106キーボード用のドライバ設定（kbd106.dll、PCAT_106KEY、タイプ「7」、サブタイプ「2」）を永続化するためのレジストリ書き換えコマンドおよび PowerShell スクリプトが自動構築されること。

#### STV-L2-002 ディスク構成と自動パーティショニング設定確認 (ディスクパーティショニング設定 (F-005))

- **STV-L3-002 パーティションレイアウトおよび回復パーティションのXML統合確認** [高]
  - インストール設定フォーム画面 (SCR-001) の「PartitionLayout」選択ボックスで「GPT」または「MBR」を選択した際、対応する diskpart スクリプトが自動生成されること。
  - 「RecoveryMode」で「Partition」を選択した際、システムの回復パーティションボリューム構成（サイズ定義、配置フロー）が WinPE ステージ用 XML に自動反映されること。
  - 動的な抽出スクリプトまたは固定のディスクインデックスからターゲットディスクを特定する自動パーティショニング設定が autounattend.xml 内に正しく構成されること。

#### STV-L2-003 不要プリインストールアプリ（ブロートウェア）の自動クリーンアップ確認 (ブロートウェア自動削除 (F-006))

- **STV-L3-003 既定アプリ削除PowerShellスクリプトの埋め込み確認** [中]
  - インストール設定フォーム画面 (SCR-001) の「DisableAppSuggestions」チェックボックスをONにした際、OneDrive、Copilot、Cortana、Bing、Teams、Outlook などのブロートウェア自動削除フラグがフォーム状態に保存されること。
  - 応答ファイルジェネレーター画面 (SCR-002) の XML プレビューに、不要アプリをプロビジョニング解除およびアンインストールするための PowerShell スクリプトが埋め込まれていること。
  - プリセット設定画面 (SCR-003) から「ブロートウェア一括除去」テンプレートを適用した際、メインのインストール設定フォーム画面 (SCR-001) の対応項目に設定値が一括流し込みされること。

#### STV-L2-004 デスクトップ操作環境カスタマイズ確認 (UI/UX最適化およびレジストリカスタマイズ (F-007))

- **STV-L3-004 レジストリ書き換えによるUI最適化設定の自動作成確認** [中]
  - インストール設定フォーム画面 (SCR-001) で「ClassicContextMenu」チェックボックスをONにした際、Windows 11以前のクラシックコンテキストメニューを強制有効化するレジストリ（reg.exeを用いた HKU\DefaultUser への書き込み）が定義されること。
  - ファイル拡張子の常時表示、およびアプリ提案の無効化などのUI/UX最適化処理が、DefaultUserSequence および PowerShellSequence の初期ログイン時実行コマンドとして正しく組み込まれること。
  - プリセット設定画面 (SCR-003) を通じて適用された壁紙やロック画面イメージの初期設定用 PowerShell スクリプトが、autounattend.xml に正しく注入されること。

#### STV-L2-005 ユーザーアカウントおよびセキュリティポリシー構成確認 (ユーザーアカウントおよびセキュリティポリシー設定 (F-008))
