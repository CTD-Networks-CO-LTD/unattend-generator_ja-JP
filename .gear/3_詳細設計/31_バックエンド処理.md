# バックエンド処理仕様書

本ドキュメントは、Windows 無人セットアップ応答ファイル生成システム（`unattend-generator_ja-JP`）における各バックエンド処理・生成ロジック（`GenerationContext` および各 `Modifier` パイプライン）の詳細仕様を定義したものです。

---

## バックエンド処理一覧

| 処理ID | 処理名 | 処理概要・詳細アルゴリズム | 入力データ (Input) | 出力データ (Output) | 関連API / 内部モジュール |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **BP-001** | 自動応答ファイル統合生成処理 | 入力された各種パラメータ（`GenerationContext`）を解析し、各設定の Modifier をパイプライン順に実行。XmlNode ツリー、Pass フェーズ設定、PowerShellSequence スクリプト等を統合・シリアライズして `autounattend.xml` を構築する。 | `GenerationContext`<br/>（全フォーム入力データ） | `autounattend.xml`<br/>（整形式XML文字列） | `generator_engine.js`<br/>`POST /api/generator/xml` |
| **BP-002** | 日本語キーボード・環境構成処理 | 日本語環境（ja-JP）および106/109日本語キーボード用の特化処理を自動定義。windowsPE での LayeredDriver 割り当て（`1`）に加え、レジストリ書き換えによる `kbd106.dll` / `PCAT_106KEY` の永続化、言語リスト（`New-WinUserLanguageList`）の構成とシステムプロファイルへのコピー（`Copy-UserInternationalSettingsToSystem`）コードを生成する。 | `Locale: 'ja-JP'`<br/>`Keyboard: '00000411'` | WinPE 設定ノード<br/>レジストリ変更スクリプト | `locales.js`<br/>`LocalesModifier.cs` |
| **BP-003** | ストレージ構成・パーティショニング処理 | ディスク構成およびパーティションレイアウト（MBR、GPT、自動検出）に基づき、WinPE フェーズで実行する `diskpart.txt` スクリプトおよびターゲットディスク選択ロジック（抽出スクリプト）を自動生成し、`RunSynchronousCommand` に埋め込む。 | `PartitionLayout`<br/>`RecoveryMode`<br/>ターゲットディスク条件 | `diskpart.txt`<br/>WinPE 実行コマンド定義 | `disk.js`<br/>`DiskModifier.cs` |
| **BP-004** | ブロートウェア自動クリーンアップ処理 | クリーンインストール後の不要な既定プリインストールアプリ（Teams, OneDrive, Copilot, Bing, Outlook, Xbox等）を一括/個別でプロビジョニング解除およびアンインストールする PowerShell スクリプト（`Remove-AppxProvisionedPackage`）を生成し、`specialize` / `userOnce` シーケンスに埋め込む。 | アプリ削除フラグ群<br/>（`Bloatware.json` 参照） | `RemovePackage.ps1`<br/>PowerShell 実行コマンド | `bloatware.js`<br/>`BloatwareModifier.cs` |
| **BP-005** | UI/UX最適化・レジストリ注入処理 | クラシックコンテキストメニューの有効化、ファイル拡張子の常時表示、高速スタートアップ無効化、アプリ提案の非表示など、初期インストール後に `HKU\DefaultUser`（`NTUSER.DAT`）へのレジストリ書き込みおよび初期ログイン時スクリプトを自動生成・注入する。 | UI最適化フラグ群<br/>（`ClassicContextMenu` 等） | レジストリ追加コマンド<br/>DefaultUser 実行スクリプト | `optimizations.js`<br/>`OptimizationsModifier.cs` |
| **BP-006** | ユーザーアカウント・セキュリティ構成処理 | 無人セットアップにおけるローカル管理者（`Administrators`）および一般ユーザー（`Users`）のアカウント定義（最大10件）、初回自動サインオン（`AutoLogon`）、パスワード有効期限ポリシー（無期限設定）、およびアカウントロックアウト閾値・期間設定コマンドを生成する。 | アカウント一覧配列<br/>ロックアウト設定<br/>パスワード期限設定 | `oobeSystem` ユーザー要素<br/>`net accounts` コマンド | `users.js`<br/>`lockout.js`<br/>`password_expiration.js` |
| **BP-007** | クライアントサイド仮想ISO生成処理 | 生成した `autounattend.xml` を、OSおよびハイパーバイザ（Hyper-V/VMware/VirtualBox等）で CD-ROM メディアとしてブート時に認識可能な ISO 9660 規格に準拠したバイナリバッファ（2048Byteセクター構造）に動的変換し、Blob 形式で即時出力する。 | `autounattend.xml` 文字列 | `autounattend.iso`<br/>（バイナリBlobデータ） | `iso_builder.js`<br/>`POST /api/generator/iso` |
| **BP-008** | Wi-Fi自動接続構成処理 | 無人セットアップ中にワイヤレスネットワークへの接続を確立するため、Wi-Fi プロファイル（`Wifi.xml`）をシステムに配置し、`WlanSvc` サービスの起動完了待機ループスクリプトおよび `netsh wlan add profile` コマンドを生成・注入する。 | `WLANProfile.xml` 本文 | `Wifi.xml`<br/>WlanSvc 待機スクリプト | `wifi.js`<br/>`WifiModifier.cs` |
| **BP-009** | AppLockerセキュリティポリシー適用処理 | AppLocker ポリシーが指定された際、アップロードされた `AppLockerPolicy.xml` を応答ファイル内に埋め込み、`AppIDSvc`（Application Identity）サービスの自動開始および `Set-AppLockerPolicy` コマンドを注入してポリシーを強制適用する。 | `AppLockerPolicy.xml` 本文 | ポリシー埋め込みノード<br/>ポリシー適用スクリプト | `applocker.js`<br/>`AppLockerModifier.cs` |
| **BP-010** | 設定クエリ抽出・フォーム復元処理 | 既存の自動応答ファイル（XML）を読み込み、先頭コメントブロックに埋め込まれている URL クエリパラメータ文字列を正規表現スキャンにより抽出し、フォームコントロールにバインド可能な Key-Value オブジェクトへ復元する。 | `autounattend.xml` テキスト | パラメータ構成オブジェクト<br/>（`URLSearchParams`） | `form_bridge.js`<br/>`POST /api/generator/parse-xml` |
| **BP-011** | 要件バイパス・簡易設定制御処理 | Windows 11 の最小システム要件（TPM 2.0, セキュアブート, RAM制限）をバイパスするレジストリ設定（`LabConfig` キーへの注入）や、OOBE 中のネットワーク接続スキップ（`BypassNetworkCheck`）、およびプライバシー簡易設定の一括無効化を構成する。 | 各種バイパスフラグ<br/>簡易設定モード | WinPE レジストリノード<br/>`ProtectYourPC: 3` 要素 | `bypass.js`<br/>`express_settings.js` |
| **BP-012** | サーバーレスAPI連携・中継処理 | Cloudflare Workers 等のサーバーレス環境において、HTTP POST/GET リクエストで受け取ったパラメータから XML / ISO 生成ロジックを実行または中継し、適切な HTTP レスポンスヘッダー（`Content-Disposition` 等）を付与して返却する。 | HTTP リクエスト<br/>（FormData / URL クエリ） | HTTP レスポンス<br/>（XMLテキスト / ISOバイナリ） | `cloudflare-worker.js`<br/>各種 `/api/generator/*` |
