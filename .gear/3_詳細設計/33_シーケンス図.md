# シーケンス図

本ドキュメントは、Windows 無人セットアップ応答ファイル生成システム（`unattend-generator_ja-JP`）における主要な内部ロジックおよびモジュール間連携シーケンスを定義したものです。

---

## 1. 応答ファイル統合生成シーケンス
インストール設定フォームに入力された各種パラメータを解析し、無人セットアップで使用される自動応答ファイル（`autounattend.xml`）を一括構築して返却するフロー。

**参加者:**
- ユーザー (actor)
- 応答ファイルジェネレーター画面 (ui)
- EventListener (`event_listener.js`)
- GeneratorEngine (`generator_engine.js`)
- GenerationContext (`generation_context.js`)
- 各Modifierクラス (`ComputerName`, `Users` 等)
- PowerShellSequence (`powershell_sequence.js`)
- XmlNode (`xml_node.js`)

```mermaid
sequenceDiagram
    autonumber
    actor user as ユーザー
    participant ui as 応答ファイルジェネレーター画面
    participant listener as EventListener (event_listener.js)
    participant engine as GeneratorEngine (generator_engine.js)
    participant context as GenerationContext
    participant modifier as 各Modifierクラス
    participant sequence as PowerShellSequence
    participant xmlnode as XmlNode

    user->>ui: 「ダウンロード」または「プレビュー」ボタンをクリック
    ui->>listener: handleEngineAction('download', form)
    listener->>engine: generateAutounattendXml(formData)
    engine->>context: new GenerationContext(formData)
    context->>xmlnode: new XmlNode('unattend', attrs)
    context->>context: Windowsセットアップ各Pass（windowsPE, specialize等）のノード初期化
    context-->>engine: コンテキストインスタンス返却

    loop 各Modifierのパイプライン実行
        engine->>modifier: process(context)
        modifier->>context: getVal() / getBool() による設定値取得
        context-->>modifier: パラメータ値返却
        modifier->>context: embedTextFile() / xml.addChild() 設定追記
        modifier-->>engine: 処理完了
    end

    engine->>sequence: finalizePowerShellSequences(context)
    sequence->>sequence: getScript() で各フェーズのスクリプト文字列を最終化
    sequence-->>engine: スクリプト文字列返却

    engine->>xmlnode: serialize(0) 呼び出し（XML文字エスケープ適用）
    xmlnode-->>engine: 整形式 autounattend.xml テキストデータ
    engine-->>listener: XMLテキスト返却
    listener->>ui: Blob URL 経由でダウンロード開始
    ui-->>user: ファイル保存ダイアログ表示 / 保存完了
```

## 2. 日本語環境・キーボード最適化シーケンス
日本語（ja-JP）および日本語106/109キーボード特化設定と、レジストリ書き換えによる永続化コマンドを生成するフロー。

**参加者:**
- GeneratorEngine (`generator_engine.js`)
- LocalesModifier (`locales.js` / `LocalesModifier.cs`)
- GenerationContext (`generation_context.js`)
- XmlNode (windowsPE)
- PowerShellSequence (specialize)
- PowerShellSequence (firstLogon)

```mermaid
sequenceDiagram
    autonumber
    participant engine as GeneratorEngine
    participant locales as LocalesModifier
    participant context as GenerationContext
    participant winpe as XmlNode (windowsPE)
    participant specialize as PowerShellSequence (specialize)
    participant firstlogon as PowerShellSequence (firstLogon)

    engine->>locales: process(context)
    locales->>context: getVal('Keyboard'), getVal('Locale') 取得
    context-->>locales: Keyboard='00000411', Locale='ja-JP' 返却

    locales->>winpe: Microsoft-Windows-International-Core-WinPE に LayeredDriver='1' 設定追加
    locales->>winpe: InputLocale='0411:00000411', SystemLocale='ja-JP' 設定追加

    locales->>specialize: レジストリ書き換えコマンド追加 (kbd106.dll, PCAT_106KEY, タイプ7, サブタイプ2)
    locales->>firstlogon: PowerShell コマンド追加 (New-WinUserLanguageList & Copy-UserInternationalSettingsToSystem)
    locales-->>engine: 処理完了
```

## 3. ディスク構成・パーティショニングシーケンス
指定されたディスク構成およびパーティションレイアウトに基づき、diskpart スクリプトを生成し、ターゲットディスクへの適用コマンドを組み込むフロー。

**参加者:**
- GeneratorEngine (`generator_engine.js`)
- DiskModifier (`disk.js` / `DiskModifier.cs`)
- GenerationContext (`generation_context.js`)
- XmlNode (windowsPE)

```mermaid
sequenceDiagram
    autonumber
    participant engine as GeneratorEngine
    participant disk as DiskModifier
    participant context as GenerationContext
    participant winpe as XmlNode (windowsPE)

    engine->>disk: process(context)
    disk->>context: getVal('PartitionLayout'), getVal('RecoveryMode') 取得
    context-->>disk: PartitionLayout='GPT', RecoveryMode='Partition' 返却

    disk->>disk: バリデーション（空白・不整合チェック）
    disk->>disk: GPT用ディスク区画割り当て diskpart コマンド生成
    disk->>disk: 回復パーティション（WinRE）用コマンド追加
    disk->>context: writeToFilePE('X:\diskpart.txt', コマンド配列)
    disk->>winpe: RunSynchronousCommand に diskpart.exe /s X:\diskpart.txt 設定注入
    disk-->>engine: 処理完了
```

## 4. ブロートウェア自動削除シーケンス
セットアップ後にシステムのクリーンな状態を維持するため、指定されたプリインストールアプリを自動削除する PowerShell スクリプトを構築し、FirstLogon/Specialize シーケンスに登録するフロー。

**参加者:**
- GeneratorEngine (`generator_engine.js`)
- BloatwareModifier (`bloatware.js` / `BloatwareModifier.cs`)
- GenerationContext (`generation_context.js`)
- PowerShellSequence (specialize)
- PowerShellSequence (userOnce)

```mermaid
sequenceDiagram
    autonumber
    participant engine as GeneratorEngine
    participant bloatware as BloatwareModifier
    participant context as GenerationContext
    participant specialize as PowerShellSequence (specialize)
    participant useronce as PowerShellSequence (userOnce)

    engine->>bloatware: process(context)
    bloatware->>context: getBool('RemoveCopilot'), getBool('RemoveOneDrive') 等の削除フラグ取得
    context-->>bloatware: 削除フラグ状態返却

    bloatware->>bloatware: 選択されたアプリ名（*Microsoft.Copilot*等）のワイルドカード配列化
    bloatware->>context: embedTextFile('RemovePackage.ps1', Remove-AppxProvisionedPackage 削除スクリプト)
    bloatware->>specialize: RemovePackage.ps1 実行コマンド追加
    bloatware->>useronce: OneDrive 等に対する個別サイレントアンインストールコマンド追加
    bloatware-->>engine: 処理完了
```

## 5. 上流UI同期パイプラインシーケンス
GitHub Actions ワークフロー（`sync-upstream.yml`）において、上流（本家）サイトのHTML構造変更を検知し、初期表示項目数パリティおよび翻訳保護ルールを適用して安全にPRを起票・同期するフロー。

**参加者:**
- Upstream (schneegans.de)
- sync_upstream_site.js
- UpstreamCache (`.upstream-cache/sections/`)
- DocsSections (`docs/sections/`)
- test_ui_parity.js
- test_upstream_ui_sync.js
- GitHub Actions CI

```mermaid
sequenceDiagram
    autonumber
    participant upstream as 上流サイト (schneegans.de)
    participant sync as sync_upstream_site.js
    participant cache as .upstream-cache/sections/
    participant docs as docs/sections/
    participant test_parity as test_ui_parity.js
    participant test_sync as test_upstream_ui_sync.js
    participant ci as GitHub Actions CI

    ci->>sync: node build/sync_upstream_site.js --report diff_report.md
    sync->>upstream: fetch(https://schneegans.de/windows/unattend-generator/)
    upstream-->>sync: 生HTML文字列
    sync->>sync: parseUpstreamHtml() で各セクションに分割
    sync->>cache: compareWithCache() で差分比較
    cache-->>sync: diffReport返却

    alt 差分検知時 (hasChanges == true)
        ci->>sync: --update-cache --update-docs 実行
        sync->>cache: 上流セクションHTMLを書き込み更新
        sync->>sync: applyUiParityRules() でパリティ保護適用 (アカウント5枠、スクリプト3枠、コンポーネント3枠、.Hidden、AddMore)
        sync->>docs: docs/sections/*.html を書き込み更新
        ci->>test_sync: node test_tools/test_upstream_ui_sync.js 実行
        test_sync-->>ci: 静的パリティ検証合格 (PASS)
        ci->>test_parity: node test_tools/test_ui_parity.js 実行
        test_parity-->>ci: DOM統合パリティ検証合格 (PASS)
        ci->>ci: git commit & PR自動起票 / 更新
    else 差分なし
        ci->>ci: 同期完了 (差分なし)
    end
```

## 6. 画面初期化・動的項目展開・設定復元シーケンス
ブラウザでの静的ページロード時、セクションの非同期ロード、初期項目数制限、AddMore押下による動的展開、Google翻訳環境下での耐障害性探索、およびXMLインポート時の設定復元自動アンハイドの連携フロー。

**参加者:**
- ユーザー (actor)
- ブラウザ (ui / index.html)
- SectionFiles (`docs/sections/*.html`)
- AddMoreハンドラ (whenClicked)
- FormBridge (`form_bridge.js`)
- UnattendEngine (`unattend_engine.js`)

```mermaid
sequenceDiagram
    autonumber
    actor user as ユーザー
    participant ui as ブラウザ (docs/index.html)
    participant sec as docs/sections/*.html
    participant addmore as AddMoreイベントハンドラ
    participant bridge as FormBridge (form_bridge.js)
    participant engine as UnattendEngine

    ui->>sec: loadSections() で全セクションを並列非同期フェッチ
    sec-->>ui: HTML挿入 (初期5/3/3枠表示、残りは tr.Hidden / li.Hidden)
    ui->>addmore: whenClicked('input.AddMore') リスナー登録

    opt ユーザーが「Add more items」ボタンをクリック
        user->>ui: AddMore ボタン押下
        ui->>addmore: クリックイベント発火
        addmore->>addmore: getTargetContainer() で直前 table/ol を探索 (Google翻訳 <font> ラッパー走査・親コンテナ探索)
        loop 最大3回
            addmore->>ui: 次の .Hidden 要素から class="Hidden" を除去
        end
        alt すべての項目が表示済み
            addmore->>ui: button.disabled = true に設定
        end
    end

    opt 既存 autounattend.xml インポート時
        user->>ui: XMLファイルをドラッグ＆ドロップまたはファイル選択
        ui->>engine: importSettingsFromXml(xmlText)
        engine->>bridge: applyQueryToForm(commentQuery, form)
        bridge->>ui: 各フォーム要素に設定値をバインド
        bridge->>ui: 値が存在する入力欄の親 .Hidden (tr/li) を自動アンハイド
        bridge->>bridge: 全AddMoreボタンの disabled 状態を更新
        bridge-->>engine: 復元完了
    end
```
