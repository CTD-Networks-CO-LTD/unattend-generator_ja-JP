# テスト計画書（テストマップ）

本ドキュメントは、Windows 無人セットアップ応答ファイル生成システム（`unattend-generator_ja-JP`）におけるテスト全体の計画、テストマトリクス（テストマップ）、テスト種別、環境、および合格判定基準を定義したものです。

---

## 1. テスト計画概要

### 1.1 テスト目的
本テストでは、C# (.NET 10) コアライブラリおよびクライアントサイド JavaScript エンジンによる応答ファイル（`autounattend.xml`）・仮想メディア（`unattend.iso`）生成機能が、日本国内の環境（日本語106キーボード、ja-JPロケール、レジストリ最適化等）において意図通りに動作し、かつ両エンジン間で完全な等価性（パリティ）を維持していることを検証・保証します。

### 1.2 テスト対象範囲
1. **コア生成・出力ドメイン**: XML統合生成、仮想ISO生成、サーバーレスAPI応答
2. **OS構成・環境最適化ドメイン**: 日本語環境・キーボード配列、ディスク構成、ブロートウェア削除、UIカスタマイズ
3. **セキュリティ・ネットワーク構成ドメイン**: ユーザーアカウント、ロックアウト・パスワード期限ポリシー、Wi-Fi構成、AppLocker
4. **設定管理・運用ドメイン**: 既存XMLからの設定インポート、要件バイパス、CI/CD自動パリティ検証

### 1.3 合格判定基準
- **単体ビルド・C#オラクル契約テスト**: C# クラスライブラリのビルドが成功し、`verify_csharp_oracle.js`（全 196 項目、CI上では `--require-dotnet` による実 `UnattendGenerator.GenerateXml` 直接比較を含む）において、`en-US` / `ja-JP` 双方の `PEMode`（`Default` / `Generated` / `Script`）× `UseConfigurationSet` 契約マトリクス、上流基準XMLとの正規化構造一致、および負例ガード検証が 100% 合格すること。
- **JSベースライン回帰テスト**: 15 種類の代表テストケース（`test_engine_parity.js`）において、保護された `baseline_unattend_engine.js`（通常ビルドでは自動上書きされない）と `docs/unattend_engine.js` の生成ロジック出力が完全一致すること。
- **UIパリティテスト**: アカウント（5枠）、スクリプト（各3枠）、コンポーネント（3枠）の初期露出制限、AddMore動的展開、Google翻訳耐性、設定復元自動アンハイドの全テスト（`test_ui_parity.js` / `test_upstream_ui_sync.js`）が 100% 成功すること。
- **機能テスト**: 247 項目の機能検証（`test_feature_parity.js`: スマートクォート排除、高速スタートアップ無効化、対話型プロンプト・スクリプト、15枠拡張、WinPEスクリプト、UseConfigurationSet条件出力マトリクス等）が全て合格すること。
- **結合・システムテスト**: 定義された全テストケースおよび配信前ステージング検証（`verify_deployed_sites.js`）が合格し、重大な不具合が残存しないこと。
