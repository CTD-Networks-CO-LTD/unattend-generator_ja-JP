# 業務フロー

本ドキュメントは、無人セットアップ応答ファイル生成ツール（`unattend-generator_ja-JP`）における主要なユースケースごとの業務・システムフローを定義したものです。

---

## 1. キーボード・地域設定フロー
日本語環境（ja-JP）における106/109日本語キーボードの自動適用およびレジストリ書き換えによる永続化フロー。

**参加者:**
- インフラ管理者 (actor)
- 応答ファイルジェネレーター(UI) (system)
- Windowsセットアップ(WinPEフェーズ) (system)
- Windowsセットアップ(Specializeフェーズ) (system)

```mermaid
sequenceDiagram
    autonumber
    actor admin as インフラ管理者
    participant generator as 応答ファイルジェネレーター(UI)
    participant winpe as Windowsセットアップ(WinPEフェーズ)
    participant specialize as Windowsセットアップ(Specializeフェーズ)

    admin->>generator: 日本語設定(ja-JP)・日本語106キーボードを選択
    generator-->>admin: 設定パラメータの反映・保持完了
    Note over winpe: OSインストール開始（WinPE起動）
    winpe->>winpe: キーボードレイヤードライバを「1」に自動設定
    Note over specialize: ハードウェア検出・構成フェーズ
    specialize->>specialize: レジストリ書き換え(kbd106.dll, PCAT_106KEY, タイプ7, サブタイプ2)を実行して永続化
```

## 6. ファイル生成・出力フロー
ブラウザ内 GenerationContext による応答ファイル（`autounattend.xml`）の即時構成と ISO パッケージの生成・ダウンロードフロー。

**参加者:**
- インフラ管理者 (actor)
- 応答ファイルジェネレーター(UI) (system)
- GenerationContext(ブラウザ) (system)
- ISO 9660 Builder (system)

```mermaid
sequenceDiagram
    autonumber
    actor admin as インフラ管理者
    participant generator as 応答ファイルジェネレーター(UI)
    participant context as GenerationContext(ブラウザ)
    participant iso as ISO 9660 Builder

    admin->>generator: 「ダウンロード」または「ISOイメージダウンロード」をクリック
    generator->>context: フォームパラメータ引き渡しとXMLドキュメント構築要求
    context-->>generator: 生成された autounattend.xml の返却
    alt XML直接ダウンロード
        generator-->>admin: Blob URL経由で autounattend.xml を即時ダウンロード提供
    else ISOイメージダウンロード
        generator->>iso: autounattend.xml を内包した ISO 9660 バイナリ構築指示
        iso-->>generator: autounattend.iso の Blob データを返却
        generator-->>admin: Blob URL経由で autounattend.iso を即時ダウンロード提供
    end
```

## 7. 設定管理・インポートフロー
過去に作成した応答ファイルを読み込み、UIフォームへ瞬時に設定値を復元するインポートフロー。

**参加者:**
- インフラ管理者 (actor)
- 応答ファイルジェネレーター(UI) (system)
- FormBridge (JavaScript) (system)

```mermaid
sequenceDiagram
    autonumber
    actor admin as インフラ管理者
    participant generator as 応答ファイルジェネレーター(UI)
    participant bridge as FormBridge (JavaScript)

    admin->>generator: 既存の autounattend.xml ファイルをアップロード（D&D またはファイル選択）
    generator->>bridge: XML内のコメント（クエリ文字列）の解析依頼
    bridge->>bridge: クエリ文字列から各設定パラメータを抽出
    bridge->>generator: フォームの各要素に復元された値をマッピング
    generator-->>admin: 設定復元後のジェネレーター画面を表示
```

## 11. バリデーション・統制フロー
応答ファイル生成前に入力パラメータの不整合（管理者有無、コンピュータ名制限等）を自動判定する検証フロー。

**参加者:**
- インフラ管理者 (actor)
- 応答ファイルジェネレーター(UI) (system)
- 整合性検証ロジック(Validation) (system)

```mermaid
sequenceDiagram
    autonumber
    actor admin as インフラ管理者
    participant generator as 応答ファイルジェネレーター(UI)
    participant validator as 整合性検証ロジック(Validation)

    admin->>generator: 応答ファイル作成の実行要求
    generator->>validator: 整合性検証の実行（管理者グループの存在、コンピュータ名制限、外部XML構文等）
    alt バリデーションエラーあり
        validator-->>generator: エラーリスト返却
        generator-->>admin: エラー警告ダイアログ表示（生成抑止）
    else バリデーション成功
        validator-->>generator: 正常終了返却
        generator-->>admin: ファイル出力・プレビュー処理を実行
    end
```
