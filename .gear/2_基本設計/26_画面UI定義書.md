# 画面UI定義書

本ドキュメントは、Windows 無人セットアップ応答ファイル生成システム（`unattend-generator_ja-JP`）における各画面のUI仕様、構成要素、入力項目、イベントハンドラ、および操作フローを定義したものです。

---

# 1. SCR-001: インストール設定フォーム画面

## 1.1 画面概要
- **画面ID**: `SCR-001`
- **画面名**: インストール設定フォーム画面
- **URL**: `/index.html`（ルート `#form`）
- **対象ユーザー**: システム管理者、インフラエンジニア、キッティング担当者
- **概要**: Windows クリーンインストールに必要な言語、キーボード配列（日本語106/109）、アカウント、ディスクパーティション、ブロートウェア削除、レジストリ最適化、バイパス設定等の各種構成パラメータを入力・編集するメイン画面。

## 1.2 画面コンポーネント構成
1. **HeaderBar**: タイトルロゴ、バージョン表記、リポジトリリンク、プリセット画面遷移リンク。
2. **LanguageSection**: 言語モード、ロケール（ja-JP）、キーボード配列（00000411等）、タイムゾーン設定。
3. **HardwareSection**: プロセッサアーキテクチャ（amd64/x86/arm64）、コンピューター名設定。
4. **AccountSection**: ユーザーアカウント作成（最大10件）、パスワード難読化、有効期限ポリシー、アカウントロックアウト設定。
5. **DiskSection**: パーティションレイアウト（GPT/MBR/Automatic）、回復パーティション構成。
6. **OptimizationSection**: ブロートウェア（Teams, OneDrive, Copilot, Bing等）削除、クラシックメニュー、拡張子常時表示等のUI調整。
7. **BypassSection**: TPM/セキュアブート/RAMバイパス、ネットワーク必須チェックバイパス、簡易設定（ExpressSettings）無効化。
8. **ActionMenuBar**: プレビュー生成、XML直接ダウンロード、ISOイメージダウンロードを実行するボタン群。

## 1.3 主要入力項目・UI要素一覧

| 項目ID | 項目名（ラベル） | 要素タイプ | 必須 | 初期値 | バリデーションルール | 説明 |
| :--- | :--- | :--- | :---: | :--- | :--- | :--- |
| `LanguageMode` | 言語セットアップモード | select | ○ | `Unattended` | `Unattended` / `Interactive` | 言語設定の無人化指定。 |
| `Locale` | システムロケール | select | ○ | `ja-JP` | 有効なロケールコード | システム既定の地域・言語設定。 |
| `Keyboard` | キーボード配列 | select | ○ | `00000411` | 有効なキーボード識別子 | 日本語選択時は `kbd106.dll` / `PCAT_106KEY` レジストリ書き換えが連動。 |
| `ProcessorArchitecture` | アーキテクチャ | select | ○ | `amd64` | `amd64` / `x86` / `arm64` | 対象マシンのプロセッサ種別。 |
| `ComputerNameMode` | コンピューター名モード | select | ○ | `Random` | `Random` / `Custom` / `Script` | PC名の命名規則。`Custom` 選択時にテキスト欄が活性化。 |
| `ComputerName` | カスタムPC名 | text | - | 空文字 | 半角英数字・ハイフン、15文字以内、数字のみ不可 | カスタム指定時のコンピューター名。 |
| `UserAccountMode` | アカウント作成モード | select | ○ | `Unattended` | `Unattended` / `Interactive` | ローカルアカウントの自動作成モード。 |
| `AccountName0` | ユーザー名 (第1) | text | ○ | `User` | 半角英数字、記号不可、既存重複不可 | プライマリアカウントのユーザー名。 |
| `AccountPassword0` | パスワード (第1) | password | - | 空文字 | 制限なし（空欄可） | ログインパスワード。 |
| `AccountGroup0` | 所属グループ (第1) | select | ○ | `Administrators` | `Administrators` / `Users` | アカウントの権限グループ。 |
| `PasswordExpirationMode`| パスワード有効期限 | select | ○ | `Unlimited` | `Unlimited` / `Custom` / `Default` | パスワード無期限化ポリシーの適用。 |
| `LockoutMode` | アカウントロックアウト | select | ○ | `Default` | `Default` / `Disabled` / `Custom` | 連続ログイン失敗時のロックアウト設定。 |
| `PartitionLayout` | パーティション方式 | select | ○ | `GPT` | `GPT` / `MBR` / `Automatic` | ディスク初期化時のパーティションレイアウト。 |
| `RecoveryMode` | 回復パーティション | select | ○ | `Partition` | `Partition` / `None` | 回復環境（WinRE）用パーティションの作成有無。 |
| `ClassicContextMenu` | クラシックメニュー | checkbox | - | false | Boolean | Windows 11で旧形式右クリックメニューを強制。 |
| `ShowFileExtensions` | 拡張子の常時表示 | checkbox | - | true | Boolean | エクスプローラーでファイル拡張子を常に表示。 |
| `DisableAppSuggestions`| アプリ提案の無効化 | checkbox | - | true | Boolean | スタートメニュー等の広告・おすすめアプリ配信を停止。 |
| `BypassRequirementsCheck`| 要件チェック回避 | checkbox | - | true | Boolean | TPM 2.0 / Secure Boot / RAM制限をバイパス。 |
| `BypassNetworkCheck` | ネットワーク回避 | checkbox | - | true | Boolean | OOBEでのインターネット接続・MSアカウント必須を回避。 |
| `ExpressSettingsMode` | 簡易設定モード | select | ○ | `DisableAll` | `DisableAll` / `EnableAll` / `Interactive` | OOBEプライバシー同意画面の一括スキップ設定。 |

## 1.4 イベント・アクション一覧

| トリガー | 対象要素 | アクション内容 | 影響・システム動作 |
| :--- | :--- | :--- | :--- |
| `onChange` | `Keyboard` | キーボード配列判定 | `00000411`（日本語）選択時、WinPE LayeredDriver=1 および レジストリ永続化スクリプトの追加を自動スケジューリング。 |
| `onChange` | `ComputerNameMode` | 表示制御 | `Custom` 選択時のみ `ComputerName` 入力欄を活性化。`Script` 選択時はカスタムスクリプト入力欄を展開。 |
| `onClick` | 「ダウンロード」ボタン | クライアント生成 | フォーム値を検証後、JavaScript エンジンを呼び出し、`autounattend.xml` を即時ダウンロード。 |
| `onClick` | 「ISOイメージダウンロード」 | ISO Blob 生成 | `createIsoBlob` を実行し、`autounattend.iso` を生成・ダウンロード。 |
| `onClick` | 「プリセット」リンク | 画面遷移 | SCR-003（プリセット設定画面）をモーダル展開。 |

# 2. SCR-002: 応答ファイルジェネレーター画面

## 2.1 画面概要
- **画面ID**: `SCR-002`
- **画面名**: 応答ファイルジェネレーター画面
- **URL**: `/index.html`（ルート `#generator`）
- **対象ユーザー**: システム管理者、インフラエンジニア
- **概要**: 生成された `autounattend.xml` のハイライト付きコードプレビュー、クリップボードコピー、直接ダウンロード、および過去の XML ファイルをドロップして設定を復元するインポート機能を提供する画面。

## 2.2 画面コンポーネント構成
1. **XmlPreviewArea**: 生成された XML のシンタックスハイライト付きコード表示領域。
2. **GenerationActionGroup**: 「XMLダウンロード」「ISOダウンロード」「クリップボードにコピー」アクションボタン群。
3. **XmlImportBox**: 既存の `autounattend.xml` をドラッグ＆ドロップまたはファイル選択で読み込むインポート領域。
4. **BackToEditLink**: 入力フォーム（SCR-001）へフォーカスを戻して再編集するためのリンク。

## 2.3 イベント・アクション一覧

| トリガー | 対象要素 | アクション内容 | 影響・システム動作 |
| :--- | :--- | :--- | :--- |
| `onClick` | 「XMLダウンロード」ボタン | Blob ダウンロード | `new Blob([xmlContent], { type: 'application/xml' })` を作成し、ローカルへ保存。 |
| `onClick` | 「ISOイメージダウンロード」ボタン | ISO 生成・保存 | `createIsoBlob(xmlContent)` を実行し、ISO 9660 バイナリを保存。 |
| `onClick` | 「クリップボードにコピー」ボタン | テキストコピー | `navigator.clipboard.writeText()` によりプレビュー内容をクリップボードに格納。 |
| `onDrop` / `onChange` | `XmlImportBox` | 設定クエリ抽出・復元 | アップロードされた XML の先頭コメントからクエリ文字列を抽出し、`applyQueryToForm` により SCR-001 の各入力項目へ値を即時反映。 |

# 3. SCR-003: プリセット設定画面

## 3.1 画面概要
- **画面ID**: `SCR-003`
- **画面名**: プリセット設定画面
- **URL**: `/sections/presets.html`
- **対象ユーザー**: システム管理者、キッティング担当者
- **概要**: 用途別に最適化された構成テンプレート（「日本語クリーンインストール標準」「ブロートウェア一括除去」「開発者向け構成」等）を選択し、フォームへ一括流し込みを行う画面。

## 3.2 画面コンポーネント構成
1. **PresetCardGroup**: 各プリセットの名称、概要、設定差分（日本語106キーボード、ブロートウェア削除等）を視覚的に表示するカードレイアウト。
2. **ApplyPresetButton**: 選択したプリセットの URL クエリ文字列を解析し、メインフォームへ適用するアクションボタン。
3. **CloseButton**: プリセット選択をキャンセルしメインフォームへ戻るボタン。
