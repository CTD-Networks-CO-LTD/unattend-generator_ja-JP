# テーブル定義

本ドキュメントは、Windows 無人セットアップ応答ファイル生成システム（`unattend-generator_ja-JP`）におけるデータモデルの物理テーブル定義書です。

---

## 1. generation_contexts（生成コンテキスト管理テーブル）
自動応答ファイル生成時の全入力パラメータ、動作モード、コミット情報を保持するメインテーブル。

| カラム名 | 論理名 | データ型 | NULL | PK | FK | デフォルト値 | 説明 |
| :--- | :--- | :--- | :---: | :---: | :---: | :--- | :--- |
| `id` | コンテキストID | UUID | NO | YES | - | gen_random_uuid() | 自動応答ファイル生成コンテキストの一意識別子 |
| `mode` | 動作モード | VARCHAR(20) | NO | - | - | 'client' | ジェネレーターの動作モード (`client` / `server`) |
| `processor_architecture` | アーキテクチャ | VARCHAR(10) | NO | - | - | 'amd64' | プロセッサアーキテクチャ (`amd64`, `x86`, `arm64`) |
| `computer_name_mode` | PC名指定モード | VARCHAR(20) | NO | - | - | 'Random' | コンピューター名決定モード (`Random`, `Custom`, `Script`) |
| `computer_name` | コンピューター名 | VARCHAR(15) | YES | - | - | NULL | カスタムコンピューター名（半角英数15文字以内） |
| `language_mode` | 言語設定モード | VARCHAR(20) | NO | - | - | 'Unattended' | 言語セットアップモード (`Unattended`, `Interactive`) |
| `ui_language` | UI言語 | VARCHAR(10) | NO | - | - | 'ja-JP' | Windows セットアップのUI言語コード |
| `locale` | システムロケール | VARCHAR(10) | NO | - | - | 'ja-JP' | システム既定の地域・ロケールコード |
| `keyboard` | キーボード識別子 | VARCHAR(20) | NO | - | - | '00000411' | キーボード配列ID（`00000411` は日本語106/109配列） |
| `geo_location` | 地理的位置 | VARCHAR(10) | NO | - | - | '122' | 地理的位置ID（GeoID: 122 は日本） |
| `time_zone_mode` | タイムゾーンモード | VARCHAR(20) | NO | - | - | 'Explicit' | タイムゾーン指定モード (`Implicit`, `Explicit`) |
| `time_zone` | タイムゾーンID | VARCHAR(50) | YES | - | - | 'Tokyo Standard Time' | 設定するタイムゾーン識別子 |
| `user_account_mode` | アカウント作成モード | VARCHAR(20) | NO | - | - | 'Unattended' | ユーザーアカウント作成モード (`Unattended`, `Interactive`) |
| `auto_logon_mode` | 自動ログオンモード | VARCHAR(20) | NO | - | - | 'Enabled' | 初回自動サインオン有効化モード (`Enabled`, `Disabled`) |
| `obscure_passwords` | パスワード難読化 | BOOLEAN | NO | - | - | false | 応答ファイル内パスワードの難読化フラグ |
| `keep_sensitive_files` | 機密ファイル維持 | BOOLEAN | NO | - | - | false | セットアップ完了後に応答ファイルを維持するフラグ |
| `bypass_requirements_check` | システム要件バイパス | BOOLEAN | NO | - | - | true | TPM/セキュアブート/RAM要件バイパスフラグ |
| `bypass_network_check` | ネットワーク要件バイパス | BOOLEAN | NO | - | - | true | OOBE中ネットワーク接続要件バイパスフラグ |
| `express_settings_mode` | 簡易設定モード | VARCHAR(20) | NO | - | - | 'DisableAll' | 簡易設定（プライバシー同意等）制御モード |
| `classic_context_menu` | クラシックメニュー | BOOLEAN | NO | - | - | false | Windows 11クラシックコンテキストメニュー有効化フラグ |
| `show_file_extensions` | 拡張子常時表示 | BOOLEAN | NO | - | - | true | エクスプローラーの拡張子常時表示フラグ |
| `disable_app_suggestions` | アプリ提案無効化 | BOOLEAN | NO | - | - | true | 余計なアプリ提案・広告のレジストリ無効化フラグ |
| `commit_hash` | コミットハッシュ | VARCHAR(40) | NO | - | - | '' | 生成時に使用されたGitコミットハッシュ |

---

## 2. accounts（ローカルユーザーアカウントテーブル）
無人セットアップ適用時に自動作成されるローカルユーザー（管理者および標準ユーザー）の定義。

| カラム名 | 論理名 | データ型 | NULL | PK | FK | 説明 |
| :--- | :--- | :--- | :---: | :---: | :---: | :--- |
| `id` | アカウントID | UUID | NO | YES | - | アカウントレコードの一意識別子 |
| `generation_context_id` | 親コンテキストID | UUID | NO | - | generation_contexts(id) | 親となる生成コンテキストID（CASCADE削除） |
| `name` | ユーザー名 | VARCHAR(100) | NO | - | - | ログインユーザー名（半角英数字） |
| `display_name` | 表示名 | VARCHAR(255) | YES | - | - | アカウントのフルネーム・表示名 |
| `user_group` | 所属グループ | VARCHAR(50) | NO | - | - | 権限グループ (`Administrators` / `Users`) |
| `password` | パスワード | VARCHAR(255) | YES | - | - | ログインパスワード（平文または難読化文字列） |

---

## 3. scripts（カスタムスクリプトテーブル）
各セットアップフェーズで実行される PowerShell / CMD / REG / VBS スクリプトの定義。

| カラム名 | 論理名 | データ型 | NULL | PK | FK | 説明 |
| :--- | :--- | :--- | :---: | :---: | :---: | :--- |
| `id` | スクリプトID | UUID | NO | YES | - | スクリプトレコードの一意識別子 |
| `generation_context_id` | 親コンテキストID | UUID | NO | - | generation_contexts(id) | 親となる生成コンテキストID（CASCADE削除） |
| `phase` | 実行フェーズ | VARCHAR(30) | NO | - | - | 実行対象フェーズ (`System`, `FirstLogon`, `UserOnce`, `DefaultUser`) |
| `script_type` | スクリプト種別 | VARCHAR(10) | NO | - | - | 実行ファイル形式 (`Ps1`, `Cmd`, `Reg`, `Vbs`, `Js`) |
| `content` | スクリプト本文 | TEXT | NO | - | - | 実行するスクリプトまたはレジストリ書き換えコード本文 |

---

## 4. components_and_passes（Windowsコンポーネント設定テーブル）
応答ファイルの構成パスに直接注入されるカスタム XML 要素の定義。

| カラム名 | 論理名 | データ型 | NULL | PK | FK | 説明 |
| :--- | :--- | :--- | :---: | :---: | :---: | :--- |
| `id` | 設定ID | UUID | NO | YES | - | コンポーネント設定の一意識別子 |
| `generation_context_id` | 親コンテキストID | UUID | NO | - | generation_contexts(id) | 親となる生成コンテキストID（CASCADE削除） |
| `component_name` | コンポーネント名 | VARCHAR(255) | NO | - | - | 注入対象のWindowsコンポーネント識別子 |
| `pass_name` | 構成パス名 | VARCHAR(30) | NO | - | - | Windowsセットアップの構成パス (`windowsPE`, `specialize`, `oobeSystem` 等) |
| `content` | XML要素本文 | TEXT | NO | - | - | 挿入されるカスタムXMLマークアップ構造 |

---

## 5. wifi_profiles（Wi-Fiプロファイルテーブル）
無人セットアップ中に自動インポートされる Wi-Fi 接続設定プロファイルの定義。

| カラム名 | 論理名 | データ型 | NULL | PK | FK | 説明 |
| :--- | :--- | :--- | :---: | :---: | :---: | :--- |
| `id` | プロファイルID | UUID | NO | YES | - | Wi-Fiプロファイルの一意識別子 |
| `generation_context_id` | 親コンテキストID | UUID | NO | - | generation_contexts(id) | 親となる生成コンテキストID（CASCADE削除） |
| `wifi_mode` | Wi-Fi適用モード | VARCHAR(20) | NO | - | - | 適用モード (`Interactive`, `FromProfile`) |
| `profile_xml` | プロファイルXML | TEXT | YES | - | - | Windows純正スキーマ（WLAN_profile_v1.xsd）に準拠したXML本文 |

---

## 6. applocker_policies（AppLockerセキュリティポリシーテーブル）
アプリケーション制御を実施するための AppLocker XML ポリシーの定義。

| カラム名 | 論理名 | データ型 | NULL | PK | FK | 説明 |
| :--- | :--- | :--- | :---: | :---: | :---: | :--- |
| `id` | ポリシーID | UUID | NO | YES | - | AppLockerポリシーの一意識別子 |
| `generation_context_id` | 親コンテキストID | UUID | NO | - | generation_contexts(id) | 親となる生成コンテキストID（CASCADE削除） |
| `applocker_mode` | モード | VARCHAR(20) | NO | - | - | ポリシー設定モード (`Skip`, `Configure`) |
| `policy_xml` | ポリシーXML本文 | TEXT | YES | - | - | Windows AppLocker.xsd スキーマに合致するポリシーXML |

---

## 7. lockout_settings（アカウントロックアウト設定テーブル）
連続認証失敗時のアカウントロックアウト挙動を制御するセキュリティ設定テーブル。

| カラム名 | 論理名 | データ型 | NULL | PK | FK | 説明 |
| :--- | :--- | :--- | :---: | :---: | :---: | :--- |
| `id` | ロックアウト設定ID | UUID | NO | YES | - | ロックアウト設定の一意識別子 |
| `generation_context_id` | 親コンテキストID | UUID | NO | - | generation_contexts(id) | 親となる生成コンテキストID（CASCADE削除） |
| `lockout_mode` | ポリシーモード | VARCHAR(20) | NO | - | - | ロックアウト設定ポリシー (`Default`, `Disabled`, `Custom`) |
| `lockout_threshold` | 試行回数閾値 | INTEGER | YES | - | - | アカウントロックされるまでの無効ログイン試行許容回数 |
| `lockout_duration` | ロック期間（分） | INTEGER | YES | - | - | ロックアウトが自動解除されるまでの維持時間（分） |
| `lockout_window` | リセット時間（分） | INTEGER | YES | - | - | 失敗カウンターがリセットされるまでの時間ウィンドウ（分） |

---

## 8. password_expiration_settings（パスワード有効期限テーブル）
ローカルアカウントのパスワード有効期限ポリシーを制御する設定テーブル。

| カラム名 | 論理名 | データ型 | NULL | PK | FK | 説明 |
| :--- | :--- | :--- | :---: | :---: | :---: | :--- |
| `id` | パスワード期限ID | UUID | NO | YES | - | パスワード期限設定の一意識別子 |
| `generation_context_id` | 親コンテキストID | UUID | NO | - | generation_contexts(id) | 親となる生成コンテキストID（CASCADE削除） |
| `password_expiration_mode` | 期限モード | VARCHAR(20) | NO | - | - | 有効期限モード (`Default`, `Unlimited`, `Custom`) |
| `max_password_age` | 最大有効日数 | INTEGER | YES | - | - | パスワードの最大有効期限（日数） |
